00 // El proyecto

Un personaje nacido
de mis propias manos.

Proyecto en progreso activo

Alyra es un proyecto personal y ambicioso: crear un personaje 3D completamente original, sin shortcuts, sin assets comprados. Desde la idea inicial hasta el rigging final, todo pasa por mis manos.

El proceso comenzó con una búsqueda de referencia visual — la estética anime/3D que quería capturar — seguida de una hoja de diseño de personaje hecha a mano, y luego el modelado en Blender desde una malla en blanco. Cada extremidad, cada mechón de cabello, cada detalle de ropa está siendo modelado a mano.

Este proyecto no tiene fecha de entrega. Es un ejercicio de maestría personal — ir tan lejos como pueda: modelo base, pelo con curvas, texturas PBR, cloth simulation, y finalmente un rig funcional para animación. Todo desde cero. Todo mío.

01 // Inspiración

De la referencia
a la hoja de personaje.

Referencia visual — punto de partida estético

El primer paso en la creación de cualquier personaje es encontrar el lenguaje visual que quieres hablar. Esta referencia definió la dirección estética de Alyra: líneas limpias, proporciones anime, carácter fuerte.

A partir de ahí, con lápiz (digital) sobre papel, construí la hoja de diseño del personaje: vistas frontal y trasera, proporciones exactas, paleta de colores, detalles de ropa y accesorios. Esta hoja es la biblia del personaje — la referencia que acompaña cada sesión de modelado.

Este proyecto se actualiza. Cada fase completada es un hito real.
